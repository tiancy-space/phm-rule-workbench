# 接口清单

统一前缀 `/api`。成功时 HTTP 200，正文：

```json
{ "code": 0, "message": "ok", "data": {} }
```

失败时 `code` 与 HTTP 状态一致：400 参数或业务规则，404 不存在，409 修订号冲突或唯一约束，500 未捕获异常。`message` 是中文说明。

写操作可带请求头 `X-Operator`，记入 `create_by` / `update_by`。带 `rev` 的更新使用乐观锁，不一致返回 409「数据已被他人修改，请刷新后重试」。

逻辑删除的行默认查不到。故障按车型+来源+代码再次新增时，会恢复已删除的那一行。

在线文档：`/swagger-ui.html`，OpenAPI JSON：`/v3/api-docs`。

## 故障规则与表达式

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/faults?cx&ly&ruleMode&czdj&keyword` | 左栏列表，带流程角标和豁免数 |
| GET | `/api/faults/{id}` | 编辑页：引入清单、豁免、继承的前置、展示树 |
| POST | `/api/faults` | 新增。默认处置等级关注、判定模式待配置。同键已删除则恢复 |
| PUT | `/api/faults/{id}` | 保存判定模式、处置等级、组合式、引入项、豁免。条件组合必须能展开。已挂流程时不能改成无需干预 |
| DELETE | `/api/faults/{id}` | 正文 `{rev}`。已绑定流程时拒绝 |
| POST | `/api/expr/preview` | 组合式校验、规范写法、入库表达式、引用式、中文释义、展示树 |
| POST | `/api/expr/check` | 零 JSON 反解析。花括号、中括号、未知参数会指出位置 |
| POST | `/api/faults/{id}/simulate` | 测点试算。`windows` 的键是 `原子编号:故障代码`。前置全部通过且组合成立才算命中 |
| POST | `/api/faults/{id}/sim-sample?wantHit=` | 搜索一组命中或未命中样例 |

诊断加载时，某故障继承的前置规则与 `db/03_sample_queries.sql` 相同：启用、车型和来源命中、且没有豁免行。`FXN5C / TCMS / 3816` 只得到 `PF_OVERHAUL`。

## 处置流程

已发布流程第一次被修改时，复制出草稿版本，已发布版本保持不动，直到再次发布。绑定、解绑不改变发布状态。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/flows` | 全部流程（含步骤） |
| GET | `/api/flows/{id}` | 详情。`errors` 阻断发布，`warnings` 只提示 |
| GET | `/api/flows/by-fault/{faultId}` | 该故障绑定的流程，没有则 `data` 为 null |
| POST | `/api/flows` | `{kind:fault\|template, faultRuleId, flowName}`。空白流程含查看、结束两步 |
| POST | `/api/flows/{id}/copy` | 复制为某故障的专属草稿 |
| POST | `/api/flows/{id}/bindings` | 按清单重设绑定。专属流程不能绑成 0 条。空了的原专属流程会删掉 |
| POST | `/api/flows/{id}/unbind` | 解绑一条。专属流程至少留一条 |
| PUT | `/api/flows/{id}` | 名称、默认窗口、运行信息字段 |
| POST | `/api/flows/{id}/save-template` | `migrateBindings=false` 时另存草稿模板 |
| POST | `/api/flows/{id}/validate` | 返回详情里的校验结果 |
| POST | `/api/flows/{id}/publish` | 草稿直接发布。有阻断问题则 400 |
| DELETE | `/api/flows/{id}` | 删除。绑定的故障变为未配置 |
| POST | `/api/flows/{id}/steps` | 添加或插入。原步骤只有一个出口时自动改线 |
| PUT | `/api/flows/{id}/steps/{stepId}` | 基本信息。切换类型会重置角色和出口 |
| DELETE | `/api/flows/{id}/steps/{stepId}` | 删除。至少留一步。指向它的出口变为未配置 |
| POST | `/api/flows/{id}/steps/reorder` | `{rev, stepIds}` 按顺序重排，第一位是起点 |
| POST | `/api/flows/{id}/steps/{stepId}/copy` | 复制到该步之后 |
| POST | `/api/flows/{id}/steps/{stepId}/cards` | 加数据卡 |
| PUT | `/api/flows/{id}/cards/{cardId}` | 改数据卡 |
| DELETE | `/api/flows/{id}/cards/{cardId}` | 删除。引用它的条件改为人工判断 |
| PUT | `/api/flows/{id}/steps/{stepId}/branches` | 整体替换出口 |
| PUT | `/api/flows/{id}/steps/{stepId}/confirms` | 整体替换确认项 |

发布校验包含：出口是否配置、判断步骤至少两个分支、结束步骤要有结论、角色和标题、参数和原子是否适用绑定车型、从第一步能否走到、能否到达结束、至少一个结束节点。回环和「未绑定故障」是警告，不挡发布。

步骤主键在「已发布 → 复制草稿」时会变。接口接受复制前的旧主键并映射到新行，响应里是新主键。

## 历史试跑

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/trials?faultRuleId=` | 事件列表 |
| GET | `/api/trials/{id}` | 曲线、状态变位、故障出现点、预置答案 |
| POST | `/api/trials/{id}/steps/{stepId}/evaluate` | 该步数据卡统计和判断步骤的系统预判 |

数值卡按窗口计算 T0 值、最大、最小、平均、首值、末值、变化量、越限时长（按 2 秒一个采样点，与原型一致）。判断步骤从上到下找第一个成立的分支，都不成立则走「否则」。
